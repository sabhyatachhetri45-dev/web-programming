Website Improvements Report

Performance, Accessibility and SEO Optimization

Created by: Sabhyata Chhetri

Introduction

I worked on improving my personal portfolio website by focusing on three important areas: Performance, Accessibility, and Search Engine Optimization (SEO). My main goal was to make the website more accessible and easier to use while maintaining its original design and functionality.

1. Performance Improvements

I reviewed my website's code and made several optimizations to reduce unnecessary loading and improve the overall experience.

Changes I Made

  • Replaced external Google Fonts with system fonts to reduce external network requests.
  • Added lazy loading to the iframe so that it loads only when needed.
  • Reviewed the HTML and CSS to avoid unnecessary code and keep the page lightweight.
  • Added reduced-motion support for users who prefer fewer animations.
Result: My Lighthouse Performance score remained the same after the changes. However, I made code-level optimizations intended to reduce unnecessary requests and improve the loading experience.

2. Accessibility Improvements

Accessibility was an important part of this task. I made changes to help keyboard users, screen reader users, and people with different accessibility needs navigate my website more easily.

Changes I Made

  • Added a skip navigation link to allow keyboard users to jump directly to the main content.
  • Improved keyboard focus indicators so users can easily identify the currently selected element.
  • Added accessible labels and ARIA attributes to interactive elements.
  • Added aria-pressed to filter buttons to communicate their selected state to assistive technologies.
  • Added a descriptive title to the iframe.
  • Improved the Quick View modal with keyboard support, including Escape-key closing and keyboard focus management.
  • Added reduced-motion support for users who prefer less animation.
Result: My Lighthouse Accessibility score improved after implementing these changes. The website became easier to navigate using a keyboard and assistive technologies.

3. SEO Improvements

Search Engine Optimization helps search engines understand the content and structure of a website. I made improvements to provide clearer information about my portfolio.

Changes I Made

  • Added a descriptive page title to identify the website.
  • Added a meta description to summarize the content of the page.
  • Added the author meta tag to identify the website creator.
  • Added the robots meta tag to provide indexing instructions to search engines.
  • Used semantic HTML elements such as header, main, section, and footer.
  • Organized headings in a clear hierarchy to make the page structure easier to understand.
  • Used descriptive text to explain the content of the website.
Result: These changes provide better page structure and metadata, helping search engines understand the website's content.
