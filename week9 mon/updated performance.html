Website Improvements Report

Detailed Performance, Accessibility and SEO Optimization

Created by: Sabhyata Chhetri

Introduction

I worked on improving my personal portfolio website by focusing on three important areas: Performance, Accessibility, and Search Engine Optimization (SEO). My goal was to make the website easier to use, more accessible, and better structured while maintaining its original design.

I used Google Lighthouse to test the website before and after making improvements.

1. Performance Improvements

Website performance affects how quickly users can see and interact with page content. I reviewed my website and made several optimizations to reduce unnecessary loading.

Changes I Made

  • Replaced external Google Fonts with system fonts to reduce external network requests.
  • Added lazy loading to the iframe so it does not need to load immediately.
  • Reviewed HTML and CSS to avoid unnecessary code.
  • Added reduced-motion support for users who prefer fewer animations.

Before and After Code Comparison

Before: External Google Fonts

<link
 href="https://fonts.googleapis.com/css2?family=..."
 rel="stylesheet">

After: System Fonts

body {
    font-family: Arial, Helvetica, sans-serif;
}

System fonts reduce dependence on external font resources and can reduce additional network requests.

Before: Iframe

<iframe
 src="embedded-content.html"
 title="Embedded content">
</iframe>

After: Lazy Loading

<iframe
 src="embedded-content.html"
 title="Embedded content"
 loading="lazy">
</iframe>

Lazy loading allows the browser to delay loading the iframe until it is close to the visible area.

Analysis of Performance Results

My Lighthouse Performance score remained the same after the changes. However, I made code-level optimizations to reduce unnecessary external requests and delay loading of embedded content.

A Lighthouse score depends on multiple measurements, including loading time, main-thread activity, layout stability, network conditions, and device performance. Therefore, a code improvement does not always produce an increase in the overall score.

The individual metrics in the comparison table help identify whether specific parts of loading performance became faster or remained unchanged.

Result: The overall Performance score did not increase, but the code was optimized by reducing external font dependencies and using lazy loading.

2. Accessibility Improvements

Accessibility helps people with different needs use a website. I made changes to support keyboard users and screen reader users.

Changes I Made

  • Added a skip navigation link.
  • Improved keyboard focus indicators.
  • Added accessible labels and ARIA attributes.
  • Added aria-pressed to filter buttons.
  • Added a descriptive title to the iframe.
  • Improved Quick View modal keyboard support.
  • Added reduced-motion support.

Relevant Code Examples

Skip Navigation Link

<a href="#main-content" class="skip-link">
    Skip to main content
</a>

<main id="main-content">
    ...
</main>

Keyboard Focus Indicator

a:focus-visible,
button:focus-visible {
    outline: 3px solid #2563eb;
    outline-offset: 4px;
}

Accessible Filter Button

<button
 type="button"
 aria-pressed="true">
    All Projects
</button>
Result: My Lighthouse Accessibility score improved after implementing these changes. The website became easier to navigate using a keyboard and assistive technologies.

3. SEO Improvements

Search Engine Optimization helps search engines understand the content and structure of a website. I improved the page metadata and semantic HTML.

Changes I Made

  • Added a descriptive page title.
  • Added a meta description.
  • Added the author meta tag.
  • Added the robots meta tag.
  • Used semantic HTML elements.
  • Organized headings in a clear hierarchy.
  • Used descriptive text for website content.

Relevant Code Example

<title>
    Website Improvements | Sabhyata Chhetri
</title>

<meta name="description"
 content="A report explaining website improvements.">

<meta name="author"
 content="Sabhyata Chhetri">

<meta name="robots"
 content="index, follow">
Result: These changes provide clearer metadata and page structure, helping search engines understand the website content.

6. What I Learned

  • Performance optimization involves several different measurements.
  • Lazy loading can delay non-critical content until it is needed.
  • System fonts can reduce external font requests.
  • Keyboard navigation is important for accessibility.
  • ARIA attributes help communicate interactive states.
  • Semantic HTML and metadata improve page structure.
  • Before-and-after testing helps evaluate improvements.

7. Conclusion

Through this task, I improved my portfolio website in three areas: Performance, Accessibility, and SEO. I replaced external fonts with system fonts, added lazy loading to an iframe, and reviewed the page code. I also added keyboard accessibility features, ARIA attributes, reduced-motion support, semantic HTML, and SEO metadata.

Although the overall Lighthouse Performance score remained the same, I made useful code-level optimizations. My Accessibility score improved after the accessibility changes, and the page structure and metadata were updated for SEO.

This task taught me that a good website should not only look attractive but should also be accessible, efficient, and clearly structured.
