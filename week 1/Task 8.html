How to Create Your First HTML Page

HTML is the language used to create the structure of websites. In this tutorial, you will learn how to create a basic webpage, add content, and open your page in a web browser.

What You Need

Before creating your first webpage, make sure you have the following things ready:

  • A computer or laptop
  • A text editor such as Notepad or VS Code
  • A web browser such as Chrome or Edge
  • Basic knowledge of HTML
  • A folder to save your HTML files

Steps

  1. Open a text editor on your computer.
  2. Create a new file and save it with the .html file extension.
  3. Start your document with the <!DOCTYPE html> declaration. This tells the browser that you are using HTML5.
  4. Create the main structure using <html>, <head>, and <body> elements.
  5. Add a title inside the <title> element.
  6. Add headings, paragraphs, lists, links, and images inside the body of your webpage.
  7. Always close your HTML elements correctly to prevent unexpected results in the browser.
  8. Save the file and open it using your web browser.
  9. Check your webpage carefully and correct any mistakes in your HTML code.

Basic HTML Structure

Every basic HTML webpage follows a standard structure. You can use the following code as a starting point. 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is my first webpage.
    </p>

</body>

</html>

Useful HTML Elements

HTML Element Purpose Example
<h1> Creates the main heading Website Title
<p> Creates a paragraph Introduction text
<img> Adds an image Profile picture
<a> Creates a link Visit Website
<ul> Creates an unordered list Shopping list
<ol> Creates an ordered list Recipe steps

How Images Work in HTML

The <img> element is used to display an image on a webpage. The src attribute tells the browser where to find the image, while the alt attribute describes the image.

Important Tips

  • Use meaningful headings for your content.
  • Always add an alt attribute to meaningful images.
  • Keep your HTML code properly organized.
  • Use lowercase letters for HTML tags.
  • Test your webpage in a browser after making changes.
  • Always check that your image URLs are correct and accessible.
